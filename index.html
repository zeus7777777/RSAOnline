RSA Online

Generate keys and encrypt or decrypt text directly in your browser.

Private by design: this page uses the browser's built-in Web Crypto API. It makes no network requests and does not save or transmit your keys or messages. Keep your private key safe.

Generate a key pair

Creates an RSA-OAEP key pair using SHA-256. Keys are shown as PEM; copy and store them securely.

Encrypt

Encrypts one short message with RSA-OAEP and the recipient's public key.

RSA can only encrypt short messages directly. With a 2048-bit key and SHA-256, the limit is 190 UTF-8 bytes.

Decrypt

Decrypts Base64 ciphertext using the matching private key.

Encryption scheme: RSA-OAEP with SHA-256. This tool is intended for short text, not files or long messages. For larger data, use a well-reviewed hybrid-encryption solution.
